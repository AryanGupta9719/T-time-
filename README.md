# A Little Sorry, JAANI 💗🧸

An interactive, romantic apology experience designed especially for **Taanyaaa**. Filled with animated teddy bears, folded love letters, gentle breeze cooling animations, floating hearts, and sweet cuddles.

---

## 🌸 Features & Experience Flow

1. **Opening Question**
   - Animated teddy bear holding a pink heart.
   - "Hey Taanyaaa... 🥺💗 Are you upset with me?"
   - Two interactive choices: `[ YES, I AM UPSET 😤 ]` and `[ NO, I'M NOT UPSET 💗 ]`.

2. **Branch: If She Clicks "NO"**
   - "ACCHAAA, JAANI! 🥹💗"
   - Teddy bear with sweet sugar sign asking for a little reward.
   - If she clicks *"EK AUR BAAR POOCHHO 🙈"*: Teddy blushes shyly with paws together and asks again.
   - If she clicks *"YES, COME HERE 💋"*: Full heart explosion and hug celebration!

3. **Branch: If She Clicks "YES" — The Cool-Down Screen**
   - Teddy bear holding a cooling fan and offering a heart-shaped pillow.
   - Interactive guided breathing bubble (`Breathe in slowly... 🌬️ / Breathe out gently... 🌸`).
   - Comforting and empathetic tone without dismissing her feelings.

4. **The Pink Diary — 4 Little Apology Cards**
   - Unfolds 4 interactive sealed letters with heart wax seals:
     - **Letter 1:** *"Taanyaaa, I didn't mean to hurt you. 🥺💗"* (Teddy offers heart with both paws)
     - **Letter 2:** *"The conversation escalated..."* (Two cute characters sit together as a broken heart heals)
     - **Letter 3:** *"Dekhlio ek baar apne aap ko meri nazron se. 💗"* (Pink vanity mirror showing glowing heart reflection)
     - **Letter 4:** *"Naaraaz hogi toh manaunga main. 🥺💗"* (Two teddy bears cuddled under a pink blanket)

5. **Romantic Sorry Finale**
   - Teddy bear holding a large pink heart with **"SORRY JAANI 💗"**.
   - Emotional, sincere, and heartfelt message.

6. **Final Screen — Can I Get Sugar?**
   - Two teddy bears cuddled under a blanket with the sign *"Can I get sugar? 🥺💋"*.
   - If she clicks *"HMM, LET ME THINK 🙈"*: Respectful, shy teddy reaction with an *"Ask me again later"* button.
   - If she clicks *"YESSS, COME HERE 💋"*: Big warm cuddle animation with confetti, kisses, and repeatable sweet romantic messages!

## 💻 Local Development Instructions

### 1. Prerequisites
Ensure you have **Node.js (v18+)** installed on your system.

### 2. Installation
Open your terminal in the project directory and run:

```bash
npm install
```

### 3. Run Development Server
Start the local Vite dev server:

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:3000` (or the port displayed in your terminal).

### 4. Build for Production
To create an optimized production build:

```bash
npm run build
```

The output will be placed in the `dist` folder.

## 🚀 Deployment Instructions

### Deploy to Vercel (Recommended)
1. Push this project to a GitHub repository.
2. Go to [Vercel](https://vercel.com/) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Framework Preset: **Vite** (auto-detected).
5. Click **"Deploy"**. Your romantic link will be live in seconds!

### Deploy to Netlify
1. Log in to [Netlify](https://www.netlify.com/).
2. Drag and drop the `dist` folder into the Netlify Drop area, OR connect your GitHub repository.
3. Build command: `npm run build`
4. Publish directory: `dist`
5. Click **"Deploy Site"**.
